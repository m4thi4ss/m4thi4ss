# 👨‍💻 Sobre mim

Sou **Desenvolvedor C#/.NET Júnior**, com foco em **Backend** e atuação **Full Stack** no desenvolvimento, manutenção e evolução de aplicações corporativas.

Tenho formação em **Análise e Desenvolvimento de Sistemas pela UNINOVE** e formação complementar em **Desenvolvimento Back-End pelo SENAI São Caetano do Sul**.

Tenho experiência profissional com desenvolvimento utilizando **C# e .NET Framework**, incluindo aplicações web com **ASP.NET MVC** e **ASP.NET Web API**, além de contato com diferentes camadas das aplicações, como regras de negócio, APIs, serviços, acesso a dados e interfaces web.

Também possuo experiência com **SQL, SQL Server, MySQL, JavaScript, jQuery, HTML, CSS, Razor, Git e GitHub**, além de contato com ambientes que utilizam Azure DevOps e TFVC.

Minha experiência inclui também manutenção e evolução de sistemas existentes, debugging, análise de código, compreensão de regras de negócio e desenvolvimento de novas funcionalidades em aplicações corporativas.

Atualmente, meu objetivo é continuar aprofundando meus conhecimentos em **C#/.NET**, evoluindo para tecnologias e práticas modernas do ecossistema .NET e avançando profissionalmente em direção ao nível **Pleno**.
